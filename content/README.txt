EDITING GUIDE

Use editor/editor.html as the primary portfolio editor. It has separate tabs for:
- Basic Info: profile, contact details, photo, resume, about text
- Skills & Exp: skills and repeatable experience records
- Projects: project type, domain, tools, title, short/full descriptions, thumbnail, three screenshots with descriptions, video, Power BI, LinkedIn, GitHub and project links
- Certificates: certificate title, provider, year and verification URL

The editor saves drafts to this browser and can export/import a portfolio-backup.json file.

Editable portfolio content is organized in this folder:
- projects.js: default project catalogue
- profile.js: default profile seed
- certificates.js: default certificate seed

Uploaded media belongs in assets/profile, assets/projects, assets/certificates, and assets/resume for permanent static hosting.
For a public static deployment, copy permanent images to assets/projects/<project-name>/ and your PDF to assets/resume/your-resume.pdf.
