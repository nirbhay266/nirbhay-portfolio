How to add a new project

  1. Open this editor and choose Projects → Add project.
  2. Choose the project type and enter the domain/function, tools, title, short info, and full description.
  3. Select a thumbnail and up to three screenshots. Write a useful description for each screenshot.
  4. Add YouTube, Power BI, LinkedIn, GitHub, or another project link.
  5. Keep Show on portfolio enabled, then click Save changes.
  6. Click View portfolio to confirm the project card and open its details.
This editor saves drafts in this browser using localStorage. Use Export backup before moving computers or publishing. To permanently publish images and PDFs, place them in the assets folders described in the project README.
