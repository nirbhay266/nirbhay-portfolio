NIRBHAY KUMAR PORTFOLIO

Open index.html to view the public portfolio.
Open editor/editor.html to manage the portfolio.

Folders:
- assets: profile photo, resume, project media, and certificate media
- content: default profile, project, and certificate content
- editor: browser-based portfolio editor

The editor stores changes in this browser. Use its Export portfolio backup
feature before moving the portfolio to another computer or browser.
